# Dataset Description

## 1. Overview

The project uses a simulated healthcare dataset containing
250 patient records. It is designed for educational data
analysis and does not represent actual patients.

## 2. Dataset Attributes

| Attribute | Description |
|---|---|
| Patient_ID | Unique patient identification number |
| Age | Age of the patient |
| Gender | Gender category |
| Disease | Disease category |
| Blood_Pressure | Blood pressure reading |
| Glucose_Level | Glucose level reading |
| BMI | Body Mass Index |
| Hospital_Visits | Number of hospital visits |
| Recovery_Status | Patient recovery category |

## 3. Data Preprocessing

The dataset was prepared with missing values, a duplicate
record and an inconsistent Age data type to demonstrate
data cleaning.

The preprocessing module performs:
- Duplicate record removal.
- Conversion of Age into numeric format.
- Replacement of missing numerical values with median values.

## 4. Statistical Analysis

The application calculates:
- Mean
- Median
- Standard deviation
- Minimum
- Maximum
- Frequency distribution

## 5. Ethical Considerations

The dataset is simulated and contains no real patient
identifiers or medical records.

The results are intended only for educational purposes
and must not be used for clinical decisions.

## 6. Conclusion

The dataset provides a reproducible example for learning
healthcare data preprocessing, statistical analysis
and visualisation.
