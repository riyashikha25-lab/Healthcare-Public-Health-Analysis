# Limitations and Future Scope

## 1. Limitations

- The dataset contains simulated rather than real patient records.
- The application currently supports CSV input.
- The analysis is limited to descriptive statistics.
- No machine learning prediction model is implemented.
- The results cannot be used for medical diagnosis.

## 2. Future Scope

- Integration of authentic and anonymised public health datasets.
- Support for JSON and database inputs.
- Development of interactive dashboards.
- Implementation of machine learning models.
- Addition of advanced statistical analysis.
- Improved data validation and error handling.

## 3. Conclusion

The current application provides a basic and reproducible
healthcare data analysis system. Future improvements can
extend its functionality and analytical capabilities.
